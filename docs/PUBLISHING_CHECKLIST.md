# Publishing Checklist

Before publishing this Skill to GitHub, manually confirm:

- A `LICENSE` file is present.
- The selected license is appropriate for your goal. This project currently uses the MIT License.
- The Skill instructions are your own original work.
- No third-party paid prompt, private Skill text, or copied proprietary prompt is included.
- The repository contains only the clean Skill files you intend to publish.
- No private PDFs, course readings, or copyrighted source files are included.
- No generated personal reading notes are included unless they are safe examples.
- The examples are synthetic or otherwise safe to publish.
- No local absolute paths are included.
- No API keys, tokens, passwords, or credentials are included.
- `.gitignore` is present and appropriate.
- `README.md` explains how to use the Skill.
- `SKILL.md` describes the output order and privacy rules clearly.
- `examples/example-input.md` and `examples/example-output.md` are safe to publish.
- `requirements.txt` is accurate.
- You have checked whether you have permission to publish any included example text.
- You have reviewed GitHub repository visibility before making it public.
